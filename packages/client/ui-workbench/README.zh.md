# @deepseek-ai/dsh-client-ui-workbench

[English](README.md) | 中文

## Summary

工作台包拥有 Web/Desktop 调试工作台的布局：面板注册表、基于 `ui-dockkit` 的
停靠排布、共享文件树与终端界面、响应式行为，以及编辑器与调试面板间的焦点路由。

为并行任务开发预登记的骨架条目；Task 20 填充面板注册表、布局与焦点行为。

## Use this package

通过客户端插件加载器消费浏览器导出。本包注册其文案命名空间与面板贡献；它投影
已记录的调试事件，从不组装模型请求。
